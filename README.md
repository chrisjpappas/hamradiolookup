Amateur Radio Callsign License Database Search

A small and simple program that allows you to search a HAM radio callsign and be given information about that licensee

A user will be prompted to input a callsign. Once inputted it will return desired information.

This program utilizes the website callook.info. This site uses screenshot dumps from the FCC to keep its database updated. The
API is open source and free to use. Created by HAM operator W1JDD

Doing so it will return the following information:
- Name
- Callsign
- License Class
- Location
- Grid Square
- Latitude and Longitude Coordinates
- Expiration date of the callsign

--REQUIREMENTS--
- Python 3.11.9 or higher
- import.requests (best way is to pip install requests through CMD if on Windows)
